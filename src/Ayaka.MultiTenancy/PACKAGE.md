## About

Tenant context and tenant management for .NET applications.

## Key Features

* Read the current tenant anywhere in your code; it flows with async calls
* Keep a catalog of known tenants, in memory or in your own store
* Cache tenant lookups with HybridCache

## How to Use

* [Quickstart](https://xzelsius.github.io/Ayaka/guide/packages/multi-tenancy/quickstart) — a working tenant-aware API in a few minutes
* [Tenant context](https://xzelsius.github.io/Ayaka/guide/packages/multi-tenancy/tenant-context) — read and set the current tenant
* [Managing tenants](https://xzelsius.github.io/Ayaka/guide/packages/multi-tenancy/management/tenants) — the tenant catalog and its store
* [Caching](https://xzelsius.github.io/Ayaka/guide/packages/multi-tenancy/management/caching) — cache tenant lookups
* [Background work](https://xzelsius.github.io/Ayaka/guide/packages/multi-tenancy/guides/background-work) — tenants outside HTTP requests
